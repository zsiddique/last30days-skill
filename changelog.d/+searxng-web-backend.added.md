Added a first-class `searxng` web-search backend that queries a self-hosted SearXNG instance's JSON API directly. Set `LAST30DAYS_SEARXNG_URL` (requires `json` in the instance's `search.formats`) or pass `--web-backend=searxng`; it now preempts crawl4ai and the keyless DuckDuckGo floor in the auto-detection ladder instead of only being consulted as a last-resort fallback inside the keyless floor.
